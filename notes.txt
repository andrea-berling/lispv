			operations are leaf functions, beacuse they dont call other functions. they dont make a1...a7 registers dirty.
	[ ] calling convention
		[x] make a1 the first argument and stop this madness
			a0 is the function return register, a1...a7 are arguments
			[ ] bring back the madness
		[ ] save registers in function call
			in an example such as this
			(defun b (args x y) (+ x y))
			(b (b 10 20) (b 20 30))
			# y: nested call 
			# y: 30 
			addi a2, zero, 30 
			# x: 20 
			addi a1, zero, 20 
			jalr ra, b(zero) 
			add a2, zero, a0 
			# x: nested call 
			# y: 20 
			addi a2, zero, 20 
			# x: 10 
			addi a1, zero, 10 
			jalr ra, b(zero) 
			add a1, zero, a0 
			jalr ra, b(zero) 
			add a1, zero, a0
			the register a1 is destroyed soon after the first evaluation (that should be assigning to it) is done.
			so (b 20 30) = 50 that is going to be used as the second argument of (b (b 10 20) ...) is trashed as soon as (b 10 20) is called, because a2 is assigned to 20.
			the algorithm that is being used to compile the ast into assembly does a dfs descent, reading right to left the operands.
			we need to save the intermediate results, and move them into arguments when needed.
			# y: nested call 
			# y: 30 
			addi a2, zero, 30 
			# x: 20 
			addi a1, zero, 20 
			jalr ra, b(zero) 
			add a2, zero, a0 
			add s2, zero, a2 # save a2 in s2
			# x: nested call 
			# y: 20 
			addi a2, zero, 20 
			# x: 10 
			addi a1, zero, 10 
			jalr ra, b(zero) 
			add a1, zero, a0 
			add a2, zero, s2 # restore a2
			jalr ra, b(zero) 
			add a1, zero, a0
			moreover, when there are more than 1 levels of nesting using registers t1...t7 is not sufficient anymore. we need to make use of the stack also when calling functions
			(b_0 (b_11 1 2) (b_12 3 (b_2 4 5)))
			for every call there are MAX_ARGUMENTS**level_n words reserved for the stack. with MAX_ARGUMENTS=2
			l2: 0 0 0 0 0 0 4 5
			l1: 1 2 3 9
			l0: 3 12
			the indexes tell us what precise argument we are dealing with (the first argument of the second argument of the second argument of the main call is 4)
			what if we make use of temporary registers
			we can also think of a solution that puts the arguments in a-normal form. since the shape of the call is known at compile time, we can unravel the call. with a more complex example:
			(b_0 (b_11 (b_21 2 3) 2) (b_12 3 (b_24 4 5)))
